# Python Data Analytics Portfolio

## Repository Objective
A collection of Python projects focused on exploratory data analysis, data cleaning, visualization, customer/product analytics, time trends, and text analysis.

## Project Areas
- E-commerce and sales analysis
- Customer and banking analytics
- Website/search trends
- Product and pricing analysis
- Netflix/content analysis
- Transportation/ride analysis
- Weather analysis
- International sales/profit analysis

## Common Workflow
**Raw data → cleaning → feature preparation → exploratory analysis → visualization → business interpretation**

## Skills Demonstrated
- Pandas and NumPy
- Data cleaning
- Grouped and time-based analysis
- Visualization with Matplotlib/Seaborn/Plotly
- Text/sentiment analysis
- Business-oriented EDA

Each project folder contains its own analysis notebook/data/visuals and project-specific README where available.

## Primary Tooling
**Python | Pandas | NumPy | Matplotlib | Seaborn | Plotly | Jupyter/Colab**
