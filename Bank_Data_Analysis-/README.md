# Bank Marketing Customer Analysis — Python

## Business Objective
Analyze bank-marketing customer data to understand demographics, balances, campaign-contact behavior, and term-deposit subscription patterns.

## Business Questions
- How does subscription behavior vary by age?
- How does average balance vary by contact month?
- How does call duration vary over time?
- How are marital status and education distributed?
- Which customer groups may be useful for targeted campaigns?

## Analysis Workflow
**Data cleaning → demographic analysis → campaign/contact analysis → visualization → business interpretation**

## Techniques
- Missing-value and duplicate handling
- Pandas data manipulation
- Grouped analysis
- Categorical comparisons
- Time-based analysis
- Matplotlib/Seaborn visualization

## Tech Stack
**Python | Pandas | NumPy | Matplotlib | Seaborn | Customer Analytics**
